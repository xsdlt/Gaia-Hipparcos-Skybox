# Gaia + Hipparcos Skybox

A six-face skybox for **Kerbal Space Program 1**, made from a CDS Gaia EDR3 color flux map with bright stars rendered from the Hipparcos catalogue.

**[Download from Releases](https://github.com/xsdlt/Gaia-Hipparcos-Skybox/releases)** · **[Source credits and terms](ATTRIBUTION.md)**

Available in **2K, 4K, 8K, and 16K**. Install only one resolution at a time.

> This is an independently made replacement for the Astronomer’s Visual Pack (AVP) skybox textures. You must obtain the AVP skybox component separately. This download does not include AVP’s original textures, configuration, or plugin.

## Installation

### If you already have AVP installed

1. Close KSP.
2. Back up the six `AVP_*.dds` files in `GameData/AstronomersVisualPack/AVP_Skybox/Skybox/`.
3. Download your preferred resolution ZIP from [Releases](https://github.com/xsdlt/Gaia-Hipparcos-Skybox/releases).
4. Extract its six DDS files into that folder, replacing the files with the same names. Do not mix resolutions or rename the files.
5. Restart the game.

### Real Solar System (RSS) users — or anyone who only wants the skybox

The complete AVP visual pack is not directly compatible with RSS. If you use RSS, or want this skybox without AVP’s other visual effects, you can keep only AVP’s skybox component:

1. Manually install the [AVP main package and texture pack](https://github.com/themaster402/AstronomersVisualPack).
2. Inside `GameData/AstronomersVisualPack/`, keep only the `AVP_Skybox` folder. Move or remove the other AVP contents from that directory. Do not change RSS or other mods’ files.
3. Follow the steps above to back up and replace the six DDS files.

If another mod also provides a skybox, avoid enabling multiple skybox configurations at the same time.

## About the appearance

All four resolutions use the same color treatment and bright-star style. This skybox includes a **local visual repair of missing data in the Gaia color map**; details in the repaired area do not represent original observations.

The bright stars were rendered from the Hipparcos catalogue, with their positions approximately propagated from J1991.25 to Gaia EDR3’s J2016.0 using stellar proper motions. However, this skybox does **not** guarantee scientific accuracy for the absolute sky orientation in-game, stellar brightness, colors, or overall appearance.

## 关于画面

四档贴图采用同一套色调和亮星风格。本贴图对 Gaia 彩图的部分数据缺失进行了视觉上的局部修补；修补区域的细节不代表原始观测结果。

亮星位置依据 Hipparcos 星表绘制，按恒星自行，从 J1991.25 近似推算至 Gaia EDR3 的 J2016.0。但本天空盒**不保证游戏中的绝对天球朝向、恒星亮度、颜色或整体画面达到科研用途所需的精度**。
