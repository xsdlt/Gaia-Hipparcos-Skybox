This is a six-face skybox for Kerbal Space Program 1. Its Milky Way background is based on the CDS Gaia EDR3 color flux map, with a bright-star layer rendered from the Hipparcos catalogue.
This is an independently made replacement for the AVP skybox textures. It uses the six face filenames expected by Astronomer’s Visual Pack (AVP). You must obtain the AVP skybox component separately; this download does not include AVP’s original textures, configuration, or plugin.
2K, 4K, 8K, and 16K versions are available. Install only one resolution at a time.
Installation
If you already have AVP installed
1. Close KSP.
2. Back up the six original AVP_*.dds files in GameData/AstronomersVisualPack/AVP_Skybox/Skybox/.
3. Download your preferred resolution ZIP from Releases.
4. Extract its six DDS files into that folder, replacing the files with the same names. Do not mix faces from different resolutions or rename them.
5. Restart the game.
Real Solar System (RSS) users
The complete AVP visual pack is not directly compatible with RSS. To use this skybox with RSS, keep only AVP’s skybox component:
1. Manually download and install the AVP main package and texture pack.
2. Inside GameData/AstronomersVisualPack/, keep only the AVP_Skybox folder. Move or remove the other AVP contents from that directory. Do not change RSS or other mods’ files.
3. Follow the steps under “If you already have AVP installed” to back up and replace the six DDS files.
If RSSVE or another mod also provides a skybox, avoid enabling multiple skybox configurations at the same time.
About the appearance
All four resolutions use the same color treatment and bright-star style, with brightness mapping, color adjustments, and enhanced bright stars. This skybox includes a local visual repair of missing data in the Gaia color map; details in the repaired area do not represent original observations.
Bright-star positions are based on the Hipparcos catalogue. However, this skybox does not guarantee scientific accuracy for the absolute sky orientation in-game, stellar brightness, colors, or overall appearance.
