# Gaia + Hipparcos Skybox for KSP 1

A six-face, 8192 × 8192 skybox for Kerbal Space Program 1, made from a CDS Gaia EDR3 color flux map with an added Hipparcos bright-star layer. This release is intended to replace the six `AVP_*.dds` skybox textures used by Astronomer's Visual Pack / SigmaReplacements.

## Download and install

Download the skybox ZIP from **Releases**. Extract its six DDS files into:

`GameData/AstronomersVisualPack/AVP_Skybox/Skybox/`

Back up the existing six `AVP_*.dds` files first, then replace them with the files from the ZIP. Close KSP before replacing textures. Keep the filenames unchanged. The ZIP also contains `ATTRIBUTION.txt`, which you can keep with your backup or mod documentation.

This is the **8K C version**: Gaia background scaled to 85% of the previous bright candidate, with enhanced Hipparcos bright stars. The six DDS files are BC3/DXT5 with mipmaps. No Gaia catalogues, AVP original art, or game files are included.
